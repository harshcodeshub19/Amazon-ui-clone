# Amazon Homepage UI Clone 🛒

A clean, responsive user interface clone of the Amazon homepage, built from scratch using pure **HTML5** and **CSS3**.

---

## 🚀 Live Demo
🔗 **[View Live Site](https://harshcodeshub19.github.io/Amazon-ui-clone/)**

---

## ✨ Features
- **Header & Navigation Bar:** Amazon search bar, account navigation, and delivery location UI.
- **Hero Section:** Clean banner display.
- **Product Grids:** Structured layout showcase powered by **CSS Flexbox & CSS Grid**.
- **Footer Section:** Multi-column links and back-to-top layout.
- **Semantic HTML:** Clean, readable, and structured markup.

---

## 🛠️ Built With
- **HTML5**
- **CSS3**

---

## 💻 How to Run Locally
1. Download or clone this repository to your computer.
2. Open the project folder.
3. Double-click on `index.html` to view the website in your browser.
